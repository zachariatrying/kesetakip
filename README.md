# KeseTakip

Banka şifresi istemeden tüm dijital ve fiziksel aboneliklerini tek ekranda gören, yıllık maliyetini hesaplayan ve zam/yenileme uyarıları sunan gizlilik odaklı Türkiye abonelik takipçisi.

## 🌐 Web'de Kullan
- **Canlı Adres:** https://zachariatrying.github.io/kesetakip/
- **Telefona PWA Olarak Ekleme:** Tarayıcı menüsünden **Ana Ekrana Ekle** ile uygulama gibi kullanabilirsiniz.

## 📱 Android APK İndir & Kur
1. [Build Android APK & Play AAB](https://github.com/zachariatrying/kesetakip/actions/workflows/android-apk.yml) sayfasına gidin.
2. En üstteki yeşil iş akışı koşusuna tıklayın ve alttaki **Artifacts** bölümünden **`kesetakip-debug-apk`** dosyasını indirin.
3. ZIP'ten `app-debug.apk` dosyasını çıkarıp Android cihazınıza kurun.

## 🛠️ Yerel Geliştirme
```bash
npm install
npm run dev
npm run build
npx cap sync
```
